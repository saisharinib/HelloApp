\# HelloApp Use Cases



\## Overview

This document describes the use cases for the HelloApp application. 

It serves as a reference for the features and functionality of the application.



\## Use Case 1: Start Application

Description: The user runs the HelloApp program.



Actor: User



Steps:

1\. The user opens the terminal.

2\. The user runs the Java program.

3\. The application starts.



\## Use Case 2: Display Greeting Message

Description: The application displays a greeting message.



Actor: System



Steps:

1\. The program executes the main method.

2\. The system prints a greeting message on the console.



Output:

Hello, Welcome to Hello App!
