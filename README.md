# HelloApp

## Overview
HelloApp is a simple Java program that prints a greeting message.

## Purpose
The project demonstrates a basic Java application and how to use GitHub for version control.

## Project Structure
src  - Java source code  
bin  - Compiled class files  
docs - Documentation  

## How to Run the Application

Compile:
javac -d bin src/HelloApp.java

Run:
java -cp bin HelloApp
