# HelloApp

## Project Overview
HelloApp is a simple Java application that prints a greeting message to the console.

## Purpose
The purpose of this project is to demonstrate the basic structure of a Java program and the use of Git and GitHub for version control and project management.

## Project Structure
HelloApp
│
├── src   - Contains Java source code
├── bin   - Contains compiled .class files
├── docs  - Contains project documentation
└── README.md - Project description

## How to Run the Application

1. Compile the Java program:
   javac -d bin src/HelloApp.java

2. Run the program:
   java -cp bin HelloApp

## Output
Hello, Welcome to Hello App!
